# ArcticCerfi's AutoHotkey Macros for Live2D Modelling work in Clip Studio Paint

Simple AutoHotkey v2 macros for speeding up layer renaming work in Clip Studio Paint.

I'm a Live2D modeler, and these are macros I wrote for myself and put out in public incase somebody else might find them useful.

## Warning

UI automation is **very fragile**. Back up your file, test on a copy, read my comments in the CSPLayerWalker class for more info.
Use these at your own risk. If it breaks your shit, I warned you.

Needless to say, LEAVE IT ALONE when its running. in case it goes haywire, don't panic-click and press Q to kill the script.

Run with [AutoHotkey v2](https://www.autohotkey.com/).
